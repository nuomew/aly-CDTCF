# 阿里云流量查询系统 - Cloudflare Workers 版

## 一、项目概述

### 1.1 项目名称
阿里云CDT流量查询系统（Cloudflare Workers 部署版）

### 1.2 项目描述
将原 PHP+MySQL 版本完整迁移到 Cloudflare Workers + D1 数据库，实现完全 Serverless 部署，无需自建服务器。

### 1.3 技术栈
| 组件 | 技术方案 |
|------|----------|
| 运行时 | Cloudflare Workers (ES Modules) |
| 数据库 | Cloudflare D1 (SQLite) |
| 存储 | Cloudflare KV（可选缓存） |
| 前端 | 静态 HTML + CSS + 原生 JS |
| 邮件 | Resend API |
| 加密 | Web Crypto API (AES-256-GCM / PBKDF2 / HMAC-SHA1) |
| 定时任务 | Cron Triggers |
| 部署 | Wrangler CLI |
| 构建 | 无需构建工具（原生 ES Modules） |

## 三、数据库设计（D1 SQLite）

### 3.1 数据表

| 表名 | 说明 |
|------|------|
| system_config | 系统配置键值对 |
| admin_users | 管理员账号（PBKDF2 密码哈希） |
| sessions | 登录会话（替代 PHP Session） |
| aliyun_config | 阿里云 AccessKey 配置 |
| traffic_records | 流量记录（按日期存储月累计值） |
| operation_logs | 操作日志 |
| mail_config | 邮箱配置（Resend API） |
| mail_template | 邮件模板 |

### 3.2 与原 MySQL 版本的差异
- 使用 SQLite 语法（INTEGER PRIMARY KEY AUTOINCREMENT 替代 INT AUTO_INCREMENT）
- 日期使用 TEXT 类型存储（ISO 8601 格式）
- 新增 sessions 表替代 PHP 原生 Session
- mail_config 表移除 SMTP 相关字段，改为 Resend API Key
- 布尔值使用 INTEGER（0/1）

## 五、部署指南

### 5.1 前置准备
1. 注册 [Cloudflare 账号](https://dash.cloudflare.com/sign-up)
2. 安装 [Node.js](https://nodejs.org/) (16.17.0+)
3. 注册 [Resend 账号](https://resend.com/) 获取 API Key（可选，用于邮件）

### 5.2 部署步骤

```bash
# 1. 进入 Worker 目录
cd cloudflare/worker

# 2. 安装依赖
npm install

# 3. 登录 Cloudflare
npx wrangler login

# 4. 创建 D1 数据库
npx wrangler d1 create aly-cdtcf
# 记录输出的 database_id，填入 wrangler.jsonc

# 5. 创建 KV 命名空间（可选）
npx wrangler kv namespace create KV
# 记录输出的 id，填入 wrangler.jsonc

# 6. 初始化数据库
npx wrangler d1 execute aly-cdtcf --remote --file=./worker/schema/schema.sql
npx wrangler d1 execute aly-cdtcf --remote --file=./worker/schema/seed.sql

# 7. 配置环境变量
# 编辑 wrangler.jsonc，填入：
# - database_id (步骤4获取)
# - APP_SECRET (随机字符串)
# - APP_URL (你的域名)
# - RESEND_API_KEY (Resend API Key，可选)

# 8. 本地测试
npx wrangler dev

# 9. 部署到 Cloudflare
npx wrangler deploy
```

### 5.3 部署后配置
1. 访问 `https://your-worker.workers.dev/pages/install.html` 完成安装
2. 使用安装向导创建管理员账号
3. 登录后台 `https://your-worker.workers.dev/pages/login.html`
4. 在"阿里云配置"中添加 AccessKey
5. 在"系统设置"中配置站点信息
6. 在"邮箱配置"中设置 Resend API Key（如需邮件功能）

### 5.4 自定义域名（可选）
1. 在 Cloudflare Dashboard 中添加自定义域名
2. 配置 DNS 记录指向 Workers
3. 更新 wrangler.jsonc 中的 APP_URL

## 六、流量统计业务规则（与原版一致）

- 阿里云流量接口返回**月累计值**，不是日增量
- `traffic_records` 存储的是刷新时拿到的累计值
- **禁止**对多天累计值再做 SUM 累加
- 今日流量 = 最新记录值 - 昨日记录值
- 昨日流量 = 昨日记录值 - 前日记录值
- 本月流量 = 本月最新记录值
- 配置流量使用 = 该配置最新记录值
- 排行榜 = 实例最新记录值

---

## 七、安全说明

- AccessKey Secret 使用 AES-256-GCM 加密存储（Web Crypto API）
- 管理员密码使用 PBKDF2（100,000次迭代 + SHA-256）哈希存储
- Session Token 存储在 D1 数据库中，24小时过期
- 敏感配置通过 wrangler.jsonc 的 vars 或 Cloudflare Secrets 管理
- API 路由自动处理 CORS

---

## 八、定时任务

Cron Triggers 配置为每5分钟执行一次，负责：
1. 刷新所有启用配置的流量数据
2. 检查流量告警阈值并发送邮件
3. 检查自动关机条件
4. 检查自动开机条件
5. 清理过期会话

## 九、与原 PHP 版本的功能对照

| 功能 | PHP 版本 | CF Workers 版 |
|------|----------|--------------|
| 前端流量展示 | index.php (PHP渲染) | index.html (JS fetch API) |
| 后台管理 | admin/*.php | pages/*.html + API |
| 数据库 | MySQL 5.6.50+ | Cloudflare D1 (SQLite) |
| 阿里云API调用 | PHP curl | Workers fetch |
| 加密 | PHP openssl_encrypt | Web Crypto AES-256-GCM |
| 密码哈希 | PHP password_hash | PBKDF2-SHA256 |
| Session | PHP Session | D1 sessions 表 |
| 邮件 | PHP SMTP | Resend API |
| 定时任务 | Linux Crontab | Cron Triggers |
| 部署 | PHP+Nginx 服务器 | wrangler deploy |
| 费用 | 服务器费用 | 免费额度足够中小使用 |
